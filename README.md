<b>🌐 Personal Portfolio Website<br></b>
A responsive personal portfolio website built with pure HTML5, CSS3, and JavaScript — deployed on GitHub Pages.<br>

<b>✨ Features</b><br>

Animated Hero Section — entrance animations, floating blobs, gradient background<br>
About Me — personal intro with animated stats cards<br>
Education Timeline — academic history with styled timeline<br>
Skills Grid — categorized skill tags (Frontend, Backend, Tools, Languages)<br>
Projects Showcase — project cards with tech tags and links<br>
Contact Section — contact form + social info<br>
Sticky Navbar — translucent with smooth scroll and active link highlighting<br>
Fully Responsive — works on mobile, tablet, and desktop<br>


<b>✨ Built With</b><br>
HTML<br>
CSS<br>
Javascript<br>
Github Pages<br>
